TINY FINGERS — PICTURE FIX

1. Download and extract this ZIP.
   On Samsung: My Files > Downloads > tap the ZIP > Extract.
2. Open https://github.com/AminaQatan/Tiny-Fingers-App
3. Select Add file > Upload files.
4. Upload the extracted app.js file to the main repository folder,
   beside index.html. Keep its name exactly app.js so it replaces
   the old file. Do not upload the ZIP itself.
5. Select Commit changes.
6. After the GitHub Pages deployment finishes, refresh Tiny Fingers.
